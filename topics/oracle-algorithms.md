# Oracle Algorithms

[← All topics](../README.md)

**Theory:** Boolean and reversible oracles, Hadamard interference, phase kickback, hidden bit strings and quantum query models.

**Bernstein–Vazirani:** Construct a controlled-gate oracle, recover the hidden string and interpret a measurement histogram; a four-bit example was demonstrated.

**Simon's algorithm:** The hidden XOR period, two-register oracle, measurement equations and Gaussian elimination over GF(2). Oracle construction and classical decoding were posed as exercises.

**Code:** [Bernstein–Vazirani Qiskit example](../examples/bernstein_vazirani.py).

**Outcome:** Understand how oracle structure and interference reveal hidden algebraic information.
